## 📚 Sobre o Repositório

O objetivo principal deste repositório é manter nossos arquivos sincronizados. A instância atual foi montada especificamente para a nossa jogatina extrema, contendo:

* **Otimização Extrema:** Mods focados em FPS e estabilidade de RAM (Sodium, Lithium, Ferrite Core, Embeddium).
* **Qualidade de Vida:** Melhorias no inventário, minimapas e atalhos rápidos para facilitar a exploração e construção.
* **Compatibilidade Total:** Arquivos organizados para funcionar tanto com o servidor quanto em redes locais (LAN).

## 🚀 Como instalar no seu computador

Siga as instruções abaixo dependendo do programa que você usa para jogar:

### Para quem usa o TLauncher
1. Baixe a pasta `mods` e `config` disponíveis aqui no repositório.
2. No TLauncher, selecione a versão **NeoForge 1.21.11** na lista e inicie o jogo uma vez para baixar a base.
3. Clique no ícone de pasta (Canto inferior direito) no TLauncher para abrir seus arquivos locais.
4. Cole as pastas baixadas lá dentro, substituindo os arquivos se o Windows pedir.
5. Abra o jogo novamente e pronto!
